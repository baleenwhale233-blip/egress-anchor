## 本批交付

- 首页与服务侧栏；内置 Claude、ChatGPT（含 Codex）、DeepSeek，初始全部沿用订阅。
- 自定义服务；服务持久保存、稳定 ID、单行修订检查，域名合成/排除/冲突及资源引用校验。
- 四类出口；生成优先于订阅规则的服务规则，ISP 复用现有 fail-closed TCP 代理链。
- 仅走机场保守使用可确认不含直连的固定节点/策略组；动态组、provider 组和旧版接管的组暂不支持。
- 指定 ISP 的服务 UDP 明确拒绝，防止不支持 UDP 的代理落到后续直连规则；不宣称完整严格模式。
- 落地代理基础增删改，显示引用；设置页订阅导入、选择与本地订阅地址，保留旧版维护入口。
- 配置生成与客户端应用分开。未接入显示未接入；不能将本地编译成功标为已应用。
- 检测详情显示范围和当前未验证原因，完整服务检测及自动接入未实现时不提供虚假成功。

## 组件与状态

AppShell / ClientSummary / ServiceCard / ExitSelector / ServiceDrawer / ResourceView /
SettingsView / Dialog / ErrorNotice / Toast。按钮、输入、状态色与焦点规则统一。

覆盖加载、空资源、初始沿用、保存中、已保存、待更新、失效引用、域名冲突、保存失败、
后台失联、长名称；失败保留草稿。抽屉支持 Escape、焦点约束、关闭后焦点恢复。
仅禁用正在提交的服务；多个服务保存不整页锁死。不在日常使用中请求重新确认已有选择。
订阅切换导致多个引用失效时可逐项保存修复，全部有效后才生成新订阅；期间保留上一份有效配置。

## 验证与边界

使用临时目录、合成订阅和 loopback 测试服务。验证生成规则、原规则保留、事务回退、
过期修订、资源引用、静态映射；浏览器检查桌面/窄窗口、键盘、保存、重新加载与异常态。
不读取或写入用户日常 FlClash 数据。自动发现、持久应用、独立恢复及 macOS 验收仍属后续批次。
