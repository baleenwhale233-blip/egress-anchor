## 设置与状态

| 内容 | 本批实现 |
| --- | --- |
| 出口方式、落地代理 | 保持在侧栏首屏，直接选择；快速添加落地后保留服务草稿与原修订 |
| 保护预设 | 关闭 / 推荐严格保护 / 自定义；后两项因完整保护未接通而禁用，API 同样拒绝 |
| 保护详情 | 展开 UDP、DNS、IPv6、WebRTC 的推荐值、当前配置、适用范围，说明配置不等于已生效 |
| 服务域名、排除范围 | 展示模板，允许补充和排除，继续使用已有标准化、冲突与生成规则 |
| 检测结果 | 独立显示实际出口、链路、可达性、DNS、UDP/WebRTC；尚无服务检测证据时显示未验证 |
| 检测参数 | 高级设置中展示推荐频率和超时；服务检测未开放时明确参数暂不生效 |

关闭额外保护保留指定 ISP 的固定出口和既有 UDP 拒绝。DNS/IPv6 标注客户端范围，
WebRTC 标注浏览器范围；不能据单个服务选项声称已修改全局网络或浏览器行为。
有改动时显示修改计数，取消/Escape/关闭会在侧栏内提供继续编辑或放弃修改。

`ProtectionPolicy` 保存预设与逐项覆盖；旧 `strict` 字段兼容映射，矛盾输入拒绝。
保存修订、应用状态、实际运行和检测证据分开。检测契约绑定服务修订、来源 ID 和生成版本，
身份变化后已有结果标为过期；本批尚未接入真实证据生产者，不能从本地生成或发现客户端推断已应用。

## FlClash 只读发现

- CLI 默认按当前平台已知目录发现；库调用和测试默认不读取主机客户端，必须显式注入目录。
- 支持已知 SQLite schema 2 / 21、macOS plist 和 Linux JSON 偏好；读取当前选中订阅，
  macOS 从应用元数据读取可用版本。多目录时不自动选目标。
- 限量读取数据库、WAL、偏好和运行配置，复制到私有临时目录后才使用 SQLite。
  比较读取前后文件身份；变化、未知结构和活动回滚日志均拒绝读取结果，不恢复或写入原文件。
- 若配置提供可访问的本机 HTTP 控制器，只调用 `GET /configs` 获取模式和 TUN 开关。
  拒绝远程地址和重定向；公开结果不含控制器凭据、订阅 URL 或原始文件内容。
- 未发现、读取失败、结构不支持、多目录、控制器不可达分别显示原因与重新检查入口。
  慢请求不占服务状态锁，页面刷新客户端信息时不重建正在编辑的表单。

“已发现”只证明元数据可读；控制器返回 TUN 开关不等于系统流量已进入 TUN。
本批不自动应用配置、不切换订阅/模式/TUN、不启动服务探测、不自动恢复。
