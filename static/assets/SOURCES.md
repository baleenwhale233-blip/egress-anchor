# Icon sources

Navigation and action symbols are unmodified SVG geometry from the official `lucide-static@0.468.0` package, assembled into a local sprite.
Source: https://lucide.dev/guide/static and https://unpkg.com/lucide-static@0.468.0/icons/ (ISC; see LUCIDE-LICENSE).

Service marks come from Lobe Icons (`@lobehub/icons-static-svg`, retrieved 2026-11-06): https://github.com/lobehub/lobe-icons (MIT; see LOBE-LICENSE). Brand marks are for identification.

No hand-drawn UI icons or raster crops from the reference are used.
